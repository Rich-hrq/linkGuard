## 为什么需要 Link Guard

### 钓鱼攻击（Phishing）

钓鱼攻击是最常见的网络威胁之一。攻击者伪造一个与真实网站外观一致的页面，诱导用户输入账号密码、银行卡信息等敏感数据。传统钓鱼使用形近域名（如 `g00gle.com`、`paypa1.com`），用户稍加留意便能识别。

但随着国际化域名（IDN）的普及，一种更隐蔽的攻击手段出现了。

### 域名同形攻击（Homograph Attack）

许多语言的字母与拉丁字母外观完全相同，但编码不同。例如：

| 字符 | 拉丁字母 | 西里尔字母 | Unicode |
|------|---------|-----------|---------|
| a / а | `a` (U+0061) | `а` (U+0430) | 外观一致，编码不同 |
| o / о | `o` (U+006F) | `о` (U+043E) | 外观一致，编码不同 |
| e / е | `e` (U+0065) | `е` (U+0435) | 外观一致，编码不同 |
| p / р | `p` (U+0070) | `р` (U+0440) | 外观一致，编码不同 |

攻击者利用这些字符注册国际化域名（IDN），构造出与真实网站几乎无法区分的链接：

```
真实网站：https://apple.com
伪造网站：https://аpple.com    ← 首字母 а 是西里尔字母 (U+0430)
```

```
真实网站：https://google.com
伪造网站：https://gооgle.com    ← 两个 о 都是西里尔字母 (U+043E)
```

在浏览器地址栏、页面链接、甚至 HTML 源码中，肉眼**完全无法分辨**。用户点击后会被导向恶意网站，而自己毫不知情。

> 这类攻击不仅限于西里尔字母。希腊字母（如 `α`、`ο`）、亚美尼亚字母等都可被利用。Link Guard 当前聚焦于西里尔字母，这是实际钓鱼攻击中最高频的滥用范围。

## Link Guard 如何防御

### 工作流程

```
用户点击链接
    │
    ▼
┌─────────────────────────────┐
│  提取链接的原始 href 属性值    │  ← 保留 Unicode 原始字符
│  （非浏览器解析后的 punycode） │
└─────────────┬───────────────┘
              │
              ▼
┌─────────────────────────────┐
│  正则匹配西里尔字母            │  ← 检测整个 URL（域名+路径+参数）
│  U+0400 ~ U+052F            │
└─────────────┬───────────────┘
              │
        ┌─────┴─────┐
        ▼           ▼
   含西里尔字母    不含西里尔字母
        │           │
        ▼           ▼
   ⚠️ alert 警告   显示顶级域名
   阻止跳转        confirm 确认
        │           │
        ▼       ┌───┴───┐
     留在当前页  ▼       ▼
              确认      取消
                │       │
                ▼       ▼
             跳转    留在当前页
```

### 关键设计

- **读取原始 href**：浏览器的 `element.href` 属性会自动将 Unicode 域名转为 punycode（如 `аpple.com` → `xn--pple-43d.com`），从而绕过检测。Link Guard 使用 `getAttribute("href")` 获取原始值，确保西里尔字母不被隐藏。
- **全文 URL 扫描**：不仅检测域名，路径和查询参数中的西里尔字母同样会被拦截。
- **事件捕获拦截**：在事件捕获阶段（capture phase）调用 `preventDefault()`，在浏览器开始导航前阻止跳转。

## 行为一览

| 场景 | 行为 |
|------|------|
| URL 含西里尔字母 | `alert` 警告，阻止跳转，展示完整 URL |
| URL 不含西里尔字母 | `confirm` 弹窗展示顶级域名，用户确认后跳转 |
| 用户取消确认 | 阻止跳转，留在当前页 |
| Ctrl / Cmd / Shift + 点击 | 不拦截，由浏览器处理（新标签/窗口） |
| 右键菜单"在新标签页打开" | 不拦截（浏览器原生行为，无法监听） |
| `javascript:` / `mailto:` / `tel:` 链接 | 不拦截 |
| `file://` 等非 HTTP 协议 | 不拦截 |

## 安装

### 从源码加载（推荐开发使用）

```bash
git clone https://github.com/your-username/link-guard.git
```

1. 打开 Brave 浏览器，地址栏输入 `brave://extensions/`
2. 开启右上角 **开发者模式**
3. 点击 **加载已解压的扩展程序**
4. 选择项目中的 `browser_extension/` 目录
5. 扩展出现在列表中即安装成功

> 同样适用于 Chrome、Edge 等 Chromium 内核浏览器。

### 验证安装

打开项目中的 `test.html`，点击各类测试链接，确认弹窗行为符合预期。

## 已知限制

- **右键菜单无法拦截**：浏览器右键菜单（"在新标签页中打开" 等）不触发 DOM 事件，内容脚本无法监听。这是浏览器安全模型的限制。
- **仅检测西里尔字母**：当前版本仅覆盖西里尔字母范围（U+0400–U+052F）。希腊字母、亚美尼亚字母等其他可混淆字符暂未覆盖。
- **无白名单机制**：每次点击都会弹窗确认，尚不支持标记信任域名。
