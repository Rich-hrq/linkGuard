Link Guard 测试页面

点击以下各类链接，验证扩展的拦截与弹窗行为。

注意：右键菜单（"Open link in new tab" 等）由浏览器原生处理，不触发 DOM 点击事件，扩展无法拦截。请使用左键直接点击进行测试。

1. 正常链接（应弹出 TLD 确认框）

普通 https://www.google.com → 确认框应显示顶级域名：.com
普通 https://github.com → 确认框应显示顶级域名：.com
普通 https://zh.wikipedia.org → 确认框应显示顶级域名：.org
新国别域名 https://example.io → 确认框应显示顶级域名：.io
新国别域名 https://example.dev → 确认框应显示顶级域名：.dev

2. 西里尔字母攻击（应弹出警告并阻止）

攻击 gооgle.com（oo 是西里尔 о） → 域名中的 "о" 是西里尔字母 U+043E
攻击 аpple.com（а 是西里尔 а） → 域名首字母 "а" 是西里尔字母 U+0430
攻击 microsоft.com（о 是西里尔） → "о" 是西里尔字母 U+043E
攻击 路径中含西里尔 → 整个 URL 都会被检测
攻击 参数中含西里尔 → 查询参数中的西里尔字母也应被检测到
攻击 亚mazon.com（亚 是中日韩字符，非西里尔） → 不应被拦截（中日韩字符不属于西里尔字母）

3. 特殊链接类型（不应被拦截）

javascript: javascript:alert('hello') → 不拦截，直接执行 JS
mailto: mailto:test@example.com → 不拦截，打开邮件客户端
tel: tel:+8612345678901 → 不拦截，触发拨号
锚点 #section-test → 不拦截，页面内跳转

4. 新标签页打开（target="_blank"）

新标签 Google（新标签页） → 确认后应在新标签页打开
攻击+新标签 gооgle.com（新标签页攻击） → 应弹出西里尔警告，阻止跳转

5. 含嵌套元素的链接

嵌套 粗体文字 内的链接 → 点击粗体文字应正常触发检测
嵌套 带样式的 span → 点击 span 内文字应正常触发检测
嵌套攻击 嵌套的伪装链接 → 点击嵌套的加粗斜体文字应触发西里尔警告

6. 修饰键组合（不应拦截）

Ctrl+点击 Google（按住 Ctrl 再点击） → 不拦截，由浏览器处理（新标签页）
Cmd+点击 GitHub（macOS 按住 Cmd 再点击） → 不拦截，由浏览器处理（新标签页）
Shift+点击 example.com（按住 Shift 再点击） → 不拦截，由浏览器处理（新窗口）

7. 边界情况

HTTP http://example.com（非 HTTPS） → 应正常弹出 TLD 确认框
长 URL https://www.example.com/very/long/path/... → TLD 仍应显示 .com
子域名 https://mail.google.com → TLD 应显示 .com
多级 TLD https://www.example.co.uk → TLD 应显示 .uk（仅取最后一段）
